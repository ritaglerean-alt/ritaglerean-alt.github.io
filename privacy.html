Privacy Policy

This application is a personal integration using rclone to access the owner's Google Drive account.

Google Drive data is accessed solely to synchronize an encrypted KeePass password database between the owner's devices.

No Google user data is sold, shared with third parties, or used for advertising.

The KeePass database remains encrypted. The application does not collect or transmit the master password.

Data access can be revoked through the owner's Google Account security settings.
